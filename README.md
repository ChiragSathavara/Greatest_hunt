⚔️ GREATEST HUNT

Action-Adventure Sword Combat Game(PROJECT FILES) | C++ / Unreal Engine 5

📝 Overview

GREATEST HUNT is a third-person action-adventure game developed in Unreal Engine 5 using C++. Players engage in sword duels, manage weapons and gear, and explore immersive environments. The game emphasizes timed combat, blocking, and strategic inventory management.

⚡ Features

Sword Combat System – Timed attacks, blocks, and duels with AI enemies.

Inventory System – Manage weapons, armor, and consumables in real-time.

Enemy AI – Enemies use perception, behavior trees, and dynamic reactions in combat.

Player Health & Stamina – Real-time management with visual feedback.

Strategic Gameplay – Choose weapons and consumables wisely to succeed in duels.

🎮 Controls
Action	Key
Move	W / A / S / D

Attack / Sword Swing	Left Mouse Button
Block / Parry	Right Mouse Button
